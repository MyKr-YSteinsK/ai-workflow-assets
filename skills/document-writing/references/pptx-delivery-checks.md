# Editable PPTX delivery checks

Use for an actual PPTX export or edit when the recipient needs to keep editing it. Use the available presentation workflow for design and authoring. Save final project decks under `docs/PPT/` unless directed otherwise; treat them as public-ready project material and follow actual sharing permissions. An assistant that can read these instructions or a PPTX link does not necessarily have access to a deck editor, the local filesystem or PowerPoint.

- **Choose a path the task can verify.** For a new deck, prefer the available presentation workflow. PptxGenJS is a practical local option for creating native objects when the host already provides it. For a limited change to a supplied file, start from a copy or duplicate of the original and edit the intended objects in place. Before changing a layout or master, identify the slides that inherit it. A new deck that matches a screenshot does not preserve the original layout structure.
- **Verify the file and its rendering.** Check the intended slide count and the required native text, chart, table or diagram objects. Render the actual output in the recipient's app when available; in Windows PowerPoint, per-slide `Slide.Export` provides a PNG for each page. Look at the rendered pages for glyphs, line wraps, clipping, overlap, image crops and plotted values. For an existing deck compare changed slides and slides affected by a shared master with the originals. Mark a different renderer or an unavailable Office check explicitly.
- **Probe charts in a disposable copy.** A chart can render from cached values even when its embedded data cannot be edited, or keep displaying an old value after a workbook edit. Change one known value, verify the chart series or plotted result updates, save, reopen and check both the data and the chart again. Where automating PowerPoint, confirm the chart refreshed or re-bound to its intended data range; saving the workbook alone is insufficient. A new embedded snapshot can make literal synthetic points editable, but does not preserve an original workbook, formulas or external links. If workbook, formulas or links are part of the deliverable, preserve them in the delivered deck or its required companion sources and verify the delivered deck still uses the intended data. A backup alone does not establish that.

See the [PowerPoint Slide.Export API](https://learn.microsoft.com/en-us/office/vba/api/powerpoint.slide.export) and [PptxGenJS documentation](https://gitbrent.github.io/PptxGenJS/). Structural checks, a visual review, and a save/reopen test cover different failures; report only the layers actually checked.
