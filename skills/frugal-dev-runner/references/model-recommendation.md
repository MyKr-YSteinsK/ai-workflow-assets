# 开发对话的模型推荐

项目方向已足够明确，即将进入下一轮 Plan 制定、实施或关键审查时，在当前回复末尾推荐一个档位，并用一句话说明它适合下一步的原因。开始制定 Plan 前就可以推荐。规划已完成时，按接下来要执行的工作选档。

每个阶段提示一次。普通问答、例行进度汇报和同阶段续聊省略提示。范围或难点有实质变化时，可以重新推荐。

只依据当前任务和本文件的固定规则选档，无需联网查模型排行。多个相互依赖的步骤按一条工作线判断。

- **GPT-6.2 Sol Max** 是大部分开发任务的默认档位。
- **GPT-6.2 Sol High** 用于范围窄、做法已知、验收明确的确定性任务。仍按项目要求验收。
- **GPT-6.2 Astra Max** 用于关键设计、难定位的根因和高风险独立审查。能独立拆出的难点可在转入该步骤时单独升档。单条工作线的难题优先用 Max。
- **GPT-6.2 Sol Ultra** 用于几条能独立推进、分别验收的工作线。只有几条工作线都需要强推理时，才推荐 **GPT-6.2 Astra Ultra**。

把推荐放在 Codex 或网页版的对话正文末尾，位于 Plan、Issue、PR 和交付文档的正文之外。模型档位由用户选择。

> 下一步建议用 GPT-6.2 Sol High。已有稳定复现，只需修正一个分支并跑对应回归。
